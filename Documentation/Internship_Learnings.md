# Internship Learnings

## Overview

The ApexPlanet Data Analytics Internship provided practical
experience in different stages of the data analytics lifecycle.

## Task 1 – Data Preparation

I learned how to inspect, clean, and prepare datasets for
further analysis.

## Task 2 – Exploratory Data Analysis

I learned how to explore datasets using descriptive statistics
and visualizations to identify trends and patterns.

## Task 3 – Interactive Dashboard

I learned how to transform analytical findings into an
interactive Power BI dashboard using KPIs, charts, slicers,
Power Query, and DAX.

## Task 4 – Data Storytelling & Statistical Validation

I learned how to communicate analytical findings through
data storytelling and validate selected observations using
statistical techniques such as correlation analysis,
hypothesis testing, t-tests, and chi-square tests.

## Technical Skills

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- DAX
- Statistics
- Google Colab
- GitHub

## Overall Learning

The internship helped me understand that data analytics is
not simply about processing data or creating charts.

The main goal is to identify meaningful insights, validate
them, communicate them clearly, and use them to support
better business decisions.
