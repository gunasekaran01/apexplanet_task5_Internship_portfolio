# Sales Analysis Dashboard

## Project Overview

This project was developed as part of the ApexPlanet Data Analytics Internship (Task 3). It presents an interactive Power BI dashboard for analysing sales performance and customer behaviour.

## Objective

To perform deep-dive sales analysis and build an interactive dashboard that supports business decision-making.

## Tools Used

- Power BI Desktop
- Microsoft Excel
- Data Analytics
- Business Intelligence

## Dashboard Features

- KPI Cards
- Revenue by City
- Sales by Category
- Monthly Sales Trend
- Top 10 Products
- Customer Segmentation
- Gender Distribution
- Interactive Filters

## KPIs

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Average Quantity
